# Build your frontend with React and Next.js, assisted by AI

Index of a three-unit online course (taught in Spanish). In each unit you build a web app with React and TypeScript, test-first, working with a coding agent while you review every diff and verify it with tests.

| Unit | Template | What you build |
| :--- | :--- | :--- |
| 1 | [`frontend-course-u1-gearforge`](https://github.com/ykro/frontend-course-u1-gearforge) | **GearForge Studio** (workstation configurator): React 19, strict TypeScript, derived state, Tailwind v4, shadcn/ui, React Hook Form, Zod 4. |
| 2 | [`frontend-course-u2-pulseboard`](https://github.com/ykro/frontend-course-u2-pulseboard) | **PulseBoard** (team task board): TanStack Query, typed OpenAPI client, Firebase Auth, live Firestore and MSW. |
| 3 | [`frontend-course-u3-eventpass`](https://github.com/ykro/frontend-course-u3-eventpass) | **EventPass** (talk catalog with sign-up): Next.js 16, Server Components, Server Actions and deployment to Vercel. |

**Getting started:** open a unit template, choose **Use this template > Create a new repository**, give it your own name, make it **Private**, clone it and run `npm ci` and `npm test` in its root. The challenge contract for each unit is in its challenge guide, in the course materials.

**Requirements:** Node.js 24, Git and a GitHub account, an editor with a coding agent; for Unit 3, a Vercel account (Hobby plan).
